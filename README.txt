BLABLABEAR SCHOOL — GitHub Pages

1. Розпакуйте ZIP на комп’ютері.
2. Створіть на GitHub новий Public репозиторій, наприклад blablabear-family.
3. Add file → Upload files. Перетягніть усі файли та папку assets з архіву.
   index.html має бути одразу в корені репозиторію, а не у вкладеній папці.
   Не завантажуйте сам ZIP.
4. Натисніть Commit changes.
5. Settings → Pages → Source: Deploy from a branch.
6. Branch: main; папка: / (root); Save.
7. Коли публікація завершиться, посилання з’явиться в Settings → Pages.

Це статичний сайт: встановлення пакетів або збірка не потрібні.
Відео YouTube потребують інтернету. Відповіді зберігаються в браузері учня;
учень має завантажити PDF відповідної домашки та надіслати викладачу.
